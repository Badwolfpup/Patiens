# Patiens

A solitaire card game built with vanilla JavaScript, HTML, and CSS. "Patiens" is Swedish for "Patience" (solitaire). Includes unit tests.

## Technologies

- JavaScript, HTML, CSS

## Features

- Classic solitaire card game
- Full 52-card deck with graphical images
- Responsive web-based UI
- **Unit tests** (Script.test.js)

## Project Structure

```
Patiens/
├── Index.html          # Game page
├── Script.js           # Game logic
├── Script.test.js      # Unit tests
├── Styles.css          # Styling
└── Spelkort/           # Card images
```

## How to Run

Open `Index.html` in a browser to play.

Run tests with your preferred JavaScript test runner.
